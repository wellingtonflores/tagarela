# Tagarela — Software Desktop (PC) para Terapia Fonoaudiológica em Crianças Autistas (TEA)

**Tagarela** é um software desktop (Windows/PC) desenvolvido como Trabalho de Conclusão de Curso (TCC) em Fonoaudiologia com foco comercial/SaaS/Patente.

## 🌟 Destaques
- **Design Sensorial TEA-Friendly:** Paleta pastel de baixa luminância, sem ruídos estridentes ou buzinas.
- **Motor de Áudio Sensorial:** Acordes harmônicos senoidais para vitórias e orientação neutra grave em tentativas.
- **Modo Criança (Kiosk):** Interface imersiva e blindada com senha de 4 dígitos (PIN) para proteção dos pais.
- **Modo Adulto:** Dashboard gráfico de tempo de uso, taxa de acertos e gerenciador de metas terapêuticas.
- **Landing Page Institucional:** Página de apresentação com botão de download direto para Windows.

## 🚀 Como Executar Localmente
```bash
npm install
npm run dev
```

## 📦 Como Compilar para Windows (.exe)
```bash
npm run electron:build
```
